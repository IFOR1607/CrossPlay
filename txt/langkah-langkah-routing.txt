LANGKAH-LANGKAH ROUTING MVC SEDERHANA

Tujuan:
Membuat browser bisa mengarahkan URL yang diketik user ke controller, method,
dan parameter tertentu.

Contoh URL:
http://localhost/CrossPlay/public/auth/login

Artinya:
- auth  -> nama controller Auth
- login -> nama method login()

1. Semua request diarahkan ke public/index.php

Browser pertama kali masuk lewat folder public.
Biasanya dibantu file .htaccess agar URL seperti:

/auth/login

tetap diproses oleh:

public/index.php

Jadi index.php berperan sebagai pintu masuk utama aplikasi.

2. public/index.php memanggil file bootstrap

Di index.php, panggil file utama aplikasi.
Contoh:

require_once '../app/init.php';

File init.php biasanya memuat:
- class App
- class Controller
- file konfigurasi
- autoloader

3. Class App membaca URL dari browser

Class App bertugas mengambil URL yang diketik user.
Contoh:

auth/login

Lalu URL tersebut dipecah menjadi array:

['auth', 'login']

Biasanya diambil dari parameter:

$_GET['url']

4. Bagian pertama URL menjadi nama controller

Dari URL:

auth/login

Bagian auth digunakan untuk mencari file:

app/controllers/Auth.php

Aturan umum:
- URL memakai huruf kecil: auth
- Nama class controller memakai huruf besar di awal: Auth
- Nama file sama dengan nama class: Auth.php

5. Bagian kedua URL menjadi nama method

Dari URL:

auth/login

Bagian login digunakan untuk memanggil method:

login()

Di dalam class Auth harus ada:

class Auth extends Controller
{
    public function login()
    {
        // tampilkan halaman login
    }
}

6. Bagian URL berikutnya menjadi parameter

Contoh URL:

produk/detail/15

Artinya:
- produk -> controller Produk
- detail -> method detail()
- 15     -> parameter

Maka method yang dipanggil:

detail(15)

Contoh:

class Produk extends Controller
{
    public function detail($id)
    {
        // tampilkan detail produk berdasarkan id
    }
}

7. Jika controller atau method tidak ditulis, gunakan default

Contoh URL:

http://localhost/CrossPlay/public/

Karena user tidak mengetik controller dan method, aplikasi bisa memakai default:

- controller: Home
- method: index

Maka yang dipanggil:

app/controllers/Home.php

class Home extends Controller
{
    public function index()
    {
        // tampilkan halaman utama
    }
}

8. Jika controller atau method tidak ditemukan, tampilkan error

Jika user mengetik:

/abc/test

Tetapi file app/controllers/Abc.php tidak ada, tampilkan halaman error 404.

Jika controller ada tetapi method test() tidak ada, tampilkan juga error 404.

9. Alur routing dari awal sampai akhir

User mengetik URL di browser:

/auth/login

Alurnya:

1. Browser mengirim request ke server
2. .htaccess mengarahkan request ke public/index.php
3. index.php memuat app/init.php
4. init.php memuat class App
5. App membaca URL auth/login
6. App mencari controller Auth
7. App mencari method login
8. App menjalankan Auth::login()
9. Controller menampilkan view login

10. Struktur minimal yang nanti bisa dibuat ulang

app/
  controllers/
    Home.php
    Auth.php
  core/
    App.php
    Controller.php
  models/
  views/
    home/
      index.php
    auth/
      login.php

public/
  index.php

11. Contoh pola kode routing sederhana di class App

class App
{
    protected $controller = 'Home';
    protected $method = 'index';
    protected $params = [];

    public function __construct()
    {
        $url = $this->parseUrl();

        if (isset($url[0]) && file_exists('../app/controllers/' . ucfirst($url[0]) . '.php')) {
            $this->controller = ucfirst($url[0]);
            unset($url[0]);
        }

        require_once '../app/controllers/' . $this->controller . '.php';
        $this->controller = new $this->controller;

        if (isset($url[1]) && method_exists($this->controller, $url[1])) {
            $this->method = $url[1];
            unset($url[1]);
        }

        if (!empty($url)) {
            $this->params = array_values($url);
        }

        call_user_func_array([$this->controller, $this->method], $this->params);
    }

    public function parseUrl()
    {
        if (isset($_GET['url'])) {
            $url = rtrim($_GET['url'], '/');
            $url = filter_var($url, FILTER_SANITIZE_URL);
            return explode('/', $url);
        }
    }
}

Catatan belajar:
- Routing menentukan controller mana yang dipanggil.
- Controller menentukan method mana yang dijalankan.
- Method menentukan view atau data apa yang ditampilkan.
- URL tidak langsung membuka file view.
- User cukup mengetik URL, lalu router yang memilih file yang tepat.
